# Gothic Halloween NFT Invitation — Telegram Mini App 🕷️🎃

Інтерактивне кінематографічне цифрове Halloween-запрошення для **Telegram Mini App** та мобільних браузерів, створене повністю **українською мовою**.

Натхненне культовою композицією референсу: величний сяючий місяць, силует кажана в нічному небі, містичний спіральний пагорб, завислий над горизонтом конверт з 3D восковою печаткою та скелетною клешнею, фізичний розлом печатки та ефектний **виїзд старинного листа-пергаменту на передній план** із закріпленням індивідуального NFT-пропуску.

## 🎬 Композиція сцени та послідовність

1. **Нічне готичне небо та місяць**:
   - Величезний сяючий місяць теплого бурштинового сяйва з текстурою кратерів.
   - Силует кажана з анімованими крилами, що ковзає на фоні місяця.
   - Готичний силует знаменитого скрученого спірального пагорба біля горизонту, сухе дерево та самотній сяючий гарбуз.
   - Клубочиться фіолетовий та багряний туман, плавають іскри та частинки попелу.
2. **Конверт і Воскова Печатка з Клешнею**:
   - Чорний оксамитовий конверт зависає в центрі на тлі місяця з золотим кутовим філігранним візерунком.
   - Велика воскова печатка з глибокого темно-бордового воску з нерівними напливами та мікротріщинами.
   - Скелетно-демонічна клешня зі зчленованими кістяними фалангами та гострими обсидіановими кігтями, що фізично впиваються у віск.
   - При наведенні/дотику когти напружуються, віск розжарюється зсередини, з'являється заклик: `ТОРКНІТЬСЯ, ЩОБ ВІДКРИТИ`.
3. **Розлом і виїзд листа (Sequence 1 -> 2 з референсу)**:
   - Клік викликає раптовий стиск клешні, лунає соковитий хруст воску, удар саб-басу, дзвін та вібрація Telegram Haptics (`impactOccurred('heavy')`).
   - Симуляція Canvas розкидає 45+ полігональних осколків воску та сніп іскор.
   - Верхній клапан конверта фізично распахується у 3D, вивільняючи тепле золоте сяйво.
   - **Лист-пергамент плавно виїжджає вгору та вперед прямо з надр конверта на передній план**, перетворюючись на головний об'єкт сцени, в той час як конверт і місяць залишаються на фоні з глибиною та паралаксом!
4. **Персоналізоване запрошення та Індивідуальний NFT-токен**:
   - Каскадна кінематографічна поява тексту:
     - `ТИ ЗАПРОШЕНИЙ`
     - `[ІМ'Я], НІЧ ЧЕКАЄ НА ТЕБЕ.`
     - Подія: `ТАЄМНИЙ КОНКЛАВ ТІНЕЙ`
     - Дата: `31 ЖОВТНЯ`
     - Час: `20:00 - ДО СХОДУ СОНЦЯ`
     - Локація: `ОБСИДІАНОВИЙ СКЛЕП І СВЯТИЛИЩЕ`
     - Бейдж: `ОСОБИСТИЙ SOULBOUND NFT ТОКЕН: #SOUL-№001` (з фіксацією статусу `АКТИВОВАНО` та дати відкриття).
   - Інтерактивні дії:
     - `[ ПРИЙНЯТИ ЗАПРОШЕННЯ ]` — золота печатка `ЗАКРІПЛЕНО`, салют готичних іскор, збереження статусу в реєстрі, кнопка `Поділитися пропуском`.
     - `[ ВІДХИЛИТИ ]` — попелястий символ і напутнє слово: *"Ми пам'ятатимемо про твою відсутність..."*.

## 💎 Система відстеження та закріплення індивідуальних NFT номерів

Кожен гість, який відкриває запрошення, отримує **унікальний персональний номер**:

1. **За прямим посиланням**:
   - `/invite/001` або `?id=001` -> NFT `#SOUL-№001` (Євгеній).
   - `/invite/002` або `?id=002` -> NFT `#SOUL-№002` (Валерія).
   - `/invite/003` або `?id=003` -> NFT `#SOUL-№003` (Олександр).
2. **Через Telegram Mini App**:
   - Якщо гість запускає бот або посилання без конкретного id, система автоматично бере `Telegram.WebApp.initDataUnsafe.user.id` і виділяє унікальний детермінований номер токена (наприклад, `#SOUL-№142`).
   - Підставляє справжнє ім'я користувача з Telegram (`first_name`).
3. **Локальне збереження та трекінг**:
   - При першому відкритті фіксується дата і час (`openedAt`).
   - При натисканні `[ПРИЙНЯТИ ЗАПРОШЕННЯ]` або `[ВІДХИЛИТИ]` статус закріплюється у пам'яті (`localStorage`), тому при повторному вході гість бачить свій підтверджений пропуск.

## 🚀 Як викласти проект у Telegram (Готовність до заливки)

Проект зібраний з відносними шляхами (`base: './'`), тому `dist/` працює на **будь-якому статичному хостингу або власному сервері**:

### Варіант А: Швидкий безкоштовний деплой (Vercel або Cloudflare Pages)
1. Встановіть [Vercel CLI](https://vercel.com/cli) або відкрийте [vercel.com](https://vercel.com).
2. Виконайте в терміналі:
   ```bash
   npx vercel --prod
   ```
   (Або завантажте репозиторій на GitHub і підключіть у Vercel / Cloudflare Pages з командою білду `npm run build` і папкою `dist`).
3. Ви отримаєте постійну HTTPS-адресу, наприклад: `https://halloween-nft-invite.vercel.app`

### Варіант Б: Тестування через тунель прямо зараз (ngrok)
1. Запустіть dev-сервер:
   ```bash
   npm run dev
   ```
2. В іншому терміналі запустіть ngrok:
   ```bash
   ngrok http 5173
   ```
3. Скопіюйте отриману HTTPS-адресу (наприклад, `https://xxxx-xx-xx.ngrok-free.app`).

---

### Налаштування у Telegram (@BotFather)

1. Відкрийте [@BotFather](https://t.me/BotFather) у Telegram.
2. Надішліть команду `/newapp` (або `/myapps` -> виберіть свого бота -> **Bot Settings** -> **Menu Button** або **Edit Web App**).
3. Введіть назву: `Halloween NFT Invitation`.
4. Введіть опис та завантажте іконку за бажанням.
5. Вставте отриманий HTTPS-URL (з Vercel або ngrok).
6. Задайте коротке ім'я (short name), наприклад `invite`.
7. Готово! Ваше посилання для надсилання друзям у Telegram:
   ```
   https://t.me/ваш_бот/invite
   ```
   Або з прямим номером запрошення:
   ```
   https://t.me/ваш_бот/invite?startapp=001
   ```
